# InvestOS — Family Office Platform

Deploy on Railway: connect this repo, set environment variables, deploy.

Required env vars:
- `NODE_ENV=production`
- `JWT_SECRET` (generate: use Railway's auto-generate)
- `FRONTEND_URL=*`

Optional:
- `GMAIL_USER` — for email invites
- `GMAIL_APP_PASSWORD` — Gmail app password
- `APP_URL` — your Railway URL (for invite email links)
